# ⛽ Fuel Calculator

## 📱 Sobre o projeto

O **Fuel Calculator** é um aplicativo Android desenvolvido em Kotlin que permite calcular o custo estimado de combustível para realizar uma viagem.

O projeto foi desenvolvido com o objetivo de praticar os conhecimentos adquiridos durante os estudos de desenvolvimento Android, utilizando Kotlin e layouts em XML.

## 🚀 Funcionalidades

- Informar o preço do combustível por litro.
- Informar o consumo médio do veículo em km/l.
- Informar a distância que será percorrida.
- Calcular o custo estimado da viagem.
- Exibir os dados informados e o resultado do cálculo.

## 🛠️ Tecnologias utilizadas

- **Kotlin:** linguagem de programação utilizada no aplicativo.
- **XML:** criação das interfaces do usuário.
- **Android Studio:** ambiente de desenvolvimento.
- **Android SDK:** ferramentas para desenvolvimento Android.

## 🧮 Como funciona o cálculo?

O aplicativo utiliza os seguintes dados:

- Preço do combustível por litro.
- Consumo médio do veículo (km/l).
- Distância da viagem (km).

O cálculo é realizado da seguinte forma:

**Litros necessários = Distância ÷ Consumo médio**

**Custo total = Litros necessários × Preço do combustível**

### Exemplo

Considerando:

- Combustível: R$ 6,00 por litro.
- Consumo médio: 12 km/l.
- Distância: 120 km.

O resultado será **R$ 60,00** de custo estimado com combustível.
